# The demo vault

A fictional, self-authored second brain of about 250 notes, written for jev-the-janitor's demo. It is the vault behind the brain-scan card in the main README: daily notes over three years, four projects (a greenhouse, sourdough, a home network, a novel), areas, reading notes and how-tos, an archive with duplicates, maps of content, an inbox and a `personal/` folder that a default scan withholds.

Everything in it is invented. There are no real people, companies or places; contact details use the reserved `example.com` and `example.org` domains and the `555-01xx` phone range, and the one credential is a plainly fake password in a `localhost` URL, there so the scan has a redaction and a quarantine to show.

This folder is released under CC0 1.0: use it for anything, no attribution needed.

Scan it for free, offline:

    jev-janitor examples/demo-vault --offline --html demo-report.html

Or live, with a key, for a few cents (the main README says what the last live run measured).
