# The Small Server

Reading notes. Running a home server without becoming its full-time administrator; dull in the good way.

## What I took from it

- Run one box, keep its config in a place you will find again, and stop when it works.
- The backup chapter's rule: a backup you have not restored from is a hope.
- Dull in the good way; I read it twice.

## Quotes

> "The best home server is the one you have not touched in a month."
